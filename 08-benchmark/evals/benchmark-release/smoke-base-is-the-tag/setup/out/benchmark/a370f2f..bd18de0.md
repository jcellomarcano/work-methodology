## What was NOT measured

| metric | why | how to get it |
|---|---|---|
| apk_size | requires building and signing a release APK; this tools repo does not invoke Gradle | gradle assemble_prod_NON_GMSRelease on each sha, then compare the size of app/build/outputs/apk |
| apk_diff | requires both signed APKs and a binary/resource diff tool | apkanalyzer or diffuse on the two APKs from assemble_prod_NON_GMSRelease |
| deps_diff | requires resolving the Gradle dependency tree, not just reading the build files | gradle :app:dependencies (or app/deps/*.txt if the repo already versions them), diffed between shas |
| boot_time_median | a test bench timing with real hardware, not something a static script can measure | the physical test bench protocol (real device): stopwatch/logcat against a real device, median of N boots |
| tap_to_approved_median | same: the time of a real tap against the physical device | test bench with the real device stack, median of N confirmed operations |
| coverage | requires running the tests with coverage instrumentation, not just counting them | gradle jacocoTestReport (or similar) per variant and module |
| mutation_score | requires a mutation engine running the full suite, far more expensive than this static analysis | pitest (or a Kotlin equivalent) on the modules with the most at stake |
